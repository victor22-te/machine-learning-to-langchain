Este repositorio contiene una **ruta de aprendizaje estructurada y práctica** para formarse como **AI Engineer / Machine Learning Developer**.

Funciona simultáneamente como:
* **Plan de Estudio Técnico:** Ruta ordenada de contenidos teóricos, documentación oficial y cursos clave.
* **Libreta de Progreso Interactivo:** Casillas de verificación (`- [ ]`) para medir el avance por módulo.
* **Portafolio de Proyectos en GitHub:** Repositorio central donde se aloja el código de los proyectos desarrollados en cada fase.
