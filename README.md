## 📌 Sobre este Repositorio

Este repositorio contiene una **ruta de aprendizaje estructurada y práctica** para convertirse en **AI Engineer / Machine Learning Developer**.

Sirve como **guía de estudio personal** y al mismo tiempo como **portafolio público en GitHub**, con casillas interactiva (`- [ ]`) para dar seguimiento a cada avance.

## 💻 Portafolio de Proyectos Prácticos

A medida que avances en cada fase, irás construyendo y subiendo tus propios proyectos a este repositorio:

### 🔹 Fase 1: Fundamentos
- [ ] **Calculadora Matricial:** Motor algebraico en Python puro.
- [ ] **Package de EDA Automático:** Generador de reportes estadísticos y gráficos.

### 🔹 Fase 2: Machine Learning Tradicional
- [ ] **Segmentación de Clientes:** Clustering no supervisado con K-Means y PCA.
- [ ] **Predictor de Propensión de Compra:** Clasificador supervisado con Random Forest y XGBoost.

### 🔹 Fase 3: Deep Learning & NLP
- [ ] **Motor de Autocompletado RNN/LSTM:** Modelo de lenguaje nivel carácter en PyTorch.
- [ ] **Clasificador de Sentimientos en Español:** Fine-tuning de Transformers con Hugging Face.

### 🔹 Fase 4: LLMs, LangChain & RAG
- [ ] **Asistente RAG Multidocumento:** Chatbot para interactuar con PDFs usando LangChain y ChromaDB.
- [ ] **Agente Autónomo de Investigación:** Agente multi-paso construido con LangGraph y monitoreado en LangSmith.

### 🔹 Fase 5: Despliegue & MLOps
- [ ] **API de Inferencia Asíncrona:** Backend de alto rendimiento con FastAPI y SSE.
- [ ] **Plataforma AI SaaS en Producción:** Web App en Streamlit containerizada en Docker y evaluada con Ragas.
