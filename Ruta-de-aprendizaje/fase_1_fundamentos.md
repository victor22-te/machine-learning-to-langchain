# 🟦 Fase 1: Fundamentos de Programación, Datos y Matemáticas

> **Duración estimada:** 10 a 12 semanas (~120 horas lectivas y prácticas)  
> **Objetivo:** Construir una base sólida en Python avanzado, manipulación vectorial de datos y los conceptos matemáticos indispensables para entender cómo funcionan los algoritmos por dentro.

---

## ⏱️ Distribución de Tareas e Horas Estimadas

### 🔹 Módulo 1.1: Python para IA e Ingeniería de Software *(30 horas)*
- [ ] **1.1.1** Programación Orientada a Objetos (Clases, Herencia, Polimorfismo, Dunder Methods) `[8 hrs]`
- [ ] **1.1.2** Manejo de Entornos Virtuales (`venv`, `conda`, `poetry`) y Gestión de Dependencias `[4 hrs]`
- [ ] **1.1.3** Programación Asíncrona (`asyncio`), Decoradores y Generadores `[8 hrs]`
- [ ] **1.1.4** Buenas Prácticas: Tipo de Datos (`typing`), Linters (`ruff`, `flake8`) y Documentación `[5 hrs]`
- [ ] **1.1.5** Manejo de Archivos (JSON, CSV, Parquet) y Peticiones HTTP con `requests` `[5 hrs]`

### 🔹 Módulo 1.2: Manipulación Vectorial de Datos con NumPy y Pandas *(30 horas)*
- [ ] **1.2.1** NumPy: Arreglos n-dimensionales, Vectorización y Broadcasting `[10 hrs]`
- [ ] **1.2.2** Pandas: Series, DataFrames, Indexación y Selección Filtrada `[8 hrs]`
- [ ] **1.2.3** Limpieza de Datos: Valores Nulos, Duplicados, Casting y Transformaciones `[6 hrs]`
- [ ] **1.2.4** Operaciones Complejas: `groupby`, `merge`, `pivot_table` y Reshaping `[6 hrs]`

### 🔹 Módulo 1.3: Visualización de Datos y Análisis Exploratorio (EDA) *(15 horas)*
- [ ] **1.3.1** Gráficos Fundamentales con Matplotlib (Líneas, Dispersión, Histogramas, Cajas) `[5 hrs]`
- [ ] **1.3.2** Visualización Estilizada y Estadística con Seaborn `[5 hrs]`
- [ ] **1.3.3** Metodología de Análisis Exploratorio de Datos (EDA) en Datasets Reales `[5 hrs]`

### 🔹 Módulo 1.4: Matemáticas y Estadística para Machine Learning *(35 horas)*
- [ ] **1.4.1** Álgebra Lineal: Vectores, Matrices, Multiplicación Matricial, Transpuesta y Autovalores `[12 hrs]`
- [ ] **1.4.2** Cálculo Multivariable: Derivadas Parciales, Gradiente y Optimización por Descenso de Gradiente `[10 hrs]`
- [ ] **1.4.3** Estadística y Probabilidad: Media, Varianza, Distribución Normal y Teorema de Bayes `[13 hrs]`

## 🛠️ Ejercicios y Proyectos Prácticos

1. **Ejercicio 1: Calculadora de Álgebra Matricial en Python Puro:**  
   Crea un módulo en Python sin librerías externas que implemente la suma de matrices, multiplicación matricial, cálculo de transpuesta y producto escalar.
2. **Ejercicio 2: Análisis Exploratorio de Datos (EDA) en Pandas:**  
   Toma un dataset de Kaggle (e.g., Ventas de Ecommerce), realiza limpieza de nulos, agrega columnas calculadas y genera gráficos de tendencias con Seaborn.
3. **Proyecto Integrador de Fase 1:**  
   Desarrolla un paquete ejecutable en Python estructurado orientado a objetos que lea archivos de datos en formato CSV/JSON, calcule estadísticos descriptivos clave y genere un reporte automatizado.
