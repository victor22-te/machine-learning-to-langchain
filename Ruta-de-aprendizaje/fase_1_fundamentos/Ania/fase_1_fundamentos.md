### Módulo 1.1: Python para IA e Ingeniería de Software `[30 horas]`
* [ ] **1.1.1** Programación Orientada a Objetos: clases, herencia, polimorfismo, encapsulamiento y dunder methods (`__init__`, `__repr__`, `__call__`). `[8 hrs]`
* [ ] **1.1.2** Gestión de entornos virtuales (`venv`, `conda`, `poetry`) y administración reproducible de dependencias. `[4 hrs]`
* [ ] **1.1.3** Programación asíncrona (`asyncio`), arquitectura de eventos, decoradores avanzados y generadores (`yield`). `[8 hrs]`
* [ ] **1.1.4** Calidad de código: tipado estático con `typing`, análisis estático con linters (`ruff`, `flake8`) y docstrings estructurados. `[5 hrs]`
* [ ] **1.1.5** Entrada/salida estructurada: manipulación de JSON, CSV, Parquet y consumo de APIs HTTP con `requests` y `httpx`. `[5 hrs]`

### Módulo 1.2: Manipulación Vectorial de Datos con NumPy y Pandas `[30 horas]`
* [ ] **1.2.1** NumPy: creación e indexación de arreglos `ndarray`, operaciones vectorizadas, álgebra matricial y reglas de broadcasting. `[10 hrs]`
* [ ] **1.2.2** Pandas: estructuras de datos (Series, DataFrames), indexación posicional y basada en etiquetas (`iloc`, `loc`). `[8 hrs]`
* [ ] **1.2.3** Limpieza e imputación de datos: detección de valores nulos, registros duplicados, casting de tipos y normalización tabular. `[6 hrs]`
* [ ] **1.2.4** Transformaciones avanzadas: agrupaciones con `groupby`, combinaciones con `merge`/`join`, tablas dinámicas `pivot_table` y reshaping. `[6 hrs]`

### Módulo 1.3: Visualización de Datos y Análisis Exploratorio (EDA) `[15 horas]`
* [ ] **1.3.1** Gráficos fundacionales con Matplotlib: dispersión, líneas, histogramas, diagramas de caja y personalización de subplots. `[5 hrs]`
* [ ] **1.3.2** Visualización estadística con Seaborn: matrices de correlación (heatmaps), distribuciones conjuntas (`pairplot`, `kdeplot`). `[5 hrs]`
* [ ] **1.3.3** Metodología formal de Análisis Exploratorio de Datos (EDA): detección de anomalías, asimetrías y multicolinealidad. `[5 hrs]`

### Módulo 1.4: Matemáticas y Estadística para Machine Learning `[35 horas]`
* [ ] **1.4.1** Álgebra Lineal: espacios vectoriales, producto punto, normas matriciales, multiplicación de matrices, autovalores y autovectores. `[12 hrs]`
* [ ] **1.4.2** Cálculo Multivariable: derivadas parciales, matriz Jacobiana, vector gradiente y algoritmo de descenso de gradiente. `[10 hrs]`
* [ ] **1.4.3** Probabilidad y Estadística: medidas de tendencia central y dispersión, distribución normal, teorema del límite central e inferencia Bayesiana. `[13 hrs]`
