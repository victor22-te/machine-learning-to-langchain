## 📌 Cómo Usar esta Libreta de Estudio

Esta hoja principal es tu **panel de control de progreso general**. Cada fase dispone de un archivo `.md` individualizado con la lista de tareas específicas, tiempos sugeridos, enlaces a documentación oficial, videos recomendados, ejercicios y proyectos.

- **Para marcar tu avance:** Cambia los casilleros `- [ ]` por `- [x]`.
- **Gestión del tiempo:** Cada módulo incluye su estimación orientativa en horas lectivas + prácticas.
- **Navegación:** Abre los archivos de cada fase para consultar el contenido detallado de estudio.

## 📑 Plan de Trabajo Resumido con Lista de Tareas

### 🟦 Fase 1: Fundamentos (~120 hrs total)
- [ ] **Módulo 1.1: Python Avanzado e Ingeniería de Software para IA** *(30 hrs)*
- [ ] **Módulo 1.2: Manipulación y Análisis Vectorial de Datos (NumPy & Pandas)** *(30 hrs)*
- [ ] **Módulo 1.3: Visualización de Datos (Matplotlib & Seaborn)** *(15 hrs)*
- [ ] **Módulo 1.4: Matemáticas y Estadística Aplicada a ML** *(35 hrs)*
- [ ] **Proyecto Integrador Fase 1:** Package de Álgebra Matricial y EDA Automático *(10 hrs)*

### 🟩 Fase 2: Machine Learning Clásico (~120 hrs total)
- [ ] **Módulo 2.1: Preprocesamiento e Ingeniería de Características** *(25 hrs)*
- [ ] **Módulo 2.2: Aprendizaje Supervisado (Regresión, Árboles, Boosting)** *(35 hrs)*
- [ ] **Módulo 2.3: Aprendizaje No Supervisado (Clustering & PCA)** *(25 hrs)*
- [ ] **Módulo 2.4: Evaluación, Métricas y Optimización con Optuna** *(20 hrs)*
- [ ] **Proyecto Integrador Fase 2:** Sistema Predictivo End-to-End con Scikit-Learn y XGBoost *(15 hrs)*

### 🟧 Fase 3: Deep Learning & NLP (~140 hrs total)
- [ ] **Módulo 3.1: Redes Neuronales Artificiales (ANN / MLP)** *(30 hrs)*
- [ ] **Módulo 3.2: Framework Deep Learning con PyTorch** *(35 hrs)*
- [ ] **Módulo 3.3: Processing de Lenguaje Natural (NLP) y Word Embeddings** *(25 hrs)*
- [ ] **Módulo 3.4: Arquitectura Transformer y Mecanismos de Atención** *(30 hrs)*
- [ ] **Módulo 3.5: Ecosistema Hugging Face (Transformers & Datasets)** *(20 hrs)*
- [ ] **Proyecto Integrador Fase 3:** Clasificador/Generador de Texto Fine-Tuned en PyTorch *(15 hrs)*

### 🟪 Fase 4: LLMs, RAG, LangChain y LangGraph (~120 hrs total)
- [ ] **Módulo 4.1: Fundamentos de LLMs y Prompt Engineering** *(15 hrs)*
- [ ] **Módulo 4.2: Integración de APIs de LLMs & Modelos Locales (Ollama/LM Studio)** *(15 hrs)*
- [ ] **Módulo 4.3: Arquitectura LangChain (LCEL, Chains, Output Parsers, Memory)** *(30 hrs)*
- [ ] **Módulo 4.4: RAG (Retrieval-Augmented Generation) & Vector DBs (Chroma, FAISS)** *(30 hrs)*
- [ ] **Módulo 4.5: Agentes Autónomos con LangGraph & Observabilidad con LangSmith** *(30 hrs)*
- [ ] **Proyecto Integrador Fase 4:** Sistema RAG Multi-Agente Avanzado con LangGraph *(15 hrs)*

### 🟥 Fase 5: Despliegue, APIs y MLOps Básico (~90 hrs total)
- [ ] **Módulo 5.1: Construcción de APIs de Alto Rendimiento con FastAPI** *(20 hrs)*
- [ ] **Módulo 5.2: Interfaces Web de Usuario con Streamlit / Gradio** *(15 hrs)*
- [ ] **Módulo 5.3: Containerización con Docker & Docker-Compose** *(20 hrs)*
- [ ] **Módulo 5.4: Despliegue en la Nube (Hugging Face Spaces / Render / AWS)** *(20 hrs)*
- [ ] **Módulo 5.5: Evaluación, Monitoreo y Guardrails de LLMs** *(15 hrs)*
- [ ] **Proyecto Final de Carrera:** Aplicación Web RAG/Agente completa en Producción *(20 hrs)*
